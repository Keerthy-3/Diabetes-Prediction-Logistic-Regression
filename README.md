# Diabetes Prediction Using Logistic Regression

## Project Overview
This project uses Machine Learning to predict whether a person is diabetic or non-diabetic based on medical attributes. Logistic Regression is used as the classification algorithm.

The project is implemented using Python in Google Colab.

## Dataset
The project uses the Pima Indians Diabetes dataset.

**Features include:**
- Pregnancies
- Glucose
- BloodPressure
- SkinThickness
- Insulin
- BMI
- DiabetesPedigreeFunction
- Age

**Target:** Diabetes outcome (0 = Non-Diabetic, 1 = Diabetic)

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

- `Cavuturu_Keerthy_LogisticsR_Project.ipynb` – Jupyter Notebook containing the implementation.

## Methodology
1. Data loading and exploration
2. Data preprocessing
3. Missing value handling
4. Outlier detection and treatment
5. Feature scaling
6. Train-test splitting
7. Logistic Regression model training
8. Model evaluation using accuracy, precision, recall, F1-score, ROC-AUC, confusion matrix, and ROC curve

## Conclusion
This project demonstrates the use of Logistic Regression for diabetes prediction and provides practical experience in data preprocessing, model development, and evaluation.
